# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

# 💼 Vikyath's Portfolio

Welcome to my personal portfolio website built using **React.js** and **Vite**. This site showcases my projects, skills, resume, and contact details — designed to be fast, responsive, and user-friendly.

🔗 **Live Website**: [vikyathb49.github.io/Portfolio](https://vikyathb49.github.io/Portfolio/)

---

## 🚀 Tech Stack

- ⚛️ React.js (with React Router DOM for navigation)
- ⚡ Vite (for fast builds and development)
- 💅 SCSS (for styling and animations)
- 📧 EmailJS (for sending messages through contact form)
- 📁 GitHub Pages (for deployment)

---
## 🌐 Features

- ✅ Smooth navigation with React Router
- ✅ Responsive layout for desktop and mobile
- ✅ Animated hero section and interactive UI
- ✅ Contact form integrated with EmailJS
- ✅ Deployed to GitHub Pages

---
## 📸 Pages

- **Home** – Introduction with hero section and navbar
- **About** – Roadmap-style experience, education, and skills
- **Projects** – Featured personal and internship projects
- **Resume** – Download or view resume directly
- **Contact** – Form to send messages (auto-reply enabled)

---
